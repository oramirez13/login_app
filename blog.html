💉 SQL Injection
SQL code injection

It happens when an application includes untrusted data in a SQL query without validation. The attacker can read, modify or delete data, bypass authentication or execute commands on the server.

Example payload:
' OR '1'='1' --

Category: Injection - OWASP Top 10 #3
Cross-Site Scripting (XSS)
Script injection in the browser

It allows injecting malicious scripts into pages viewed by other users. It can be used to steal session cookies, redirect users or perform actions on behalf of the victim without their consent.

Example payload:
<script>alert(document.cookie)</script>

Category: Injection - OWASP Top 10 #3
Cross-Site Request Forgery (CSRF)
Request forgery

It tricks the browser of an authenticated victim into sending malicious requests to a web application. The server accepts them as legitimate because they come from the authenticated user's browser.

Main defense:
CSRF tokens in forms

Category: Broken Auth - OWASP Top 10 #2
Self-XSS
Social engineering in the console

The attacker convinces the victim to paste malicious JavaScript into their own browser console. The browser runs it with the user's permissions, potentially stealing sessions or sensitive data.

Firefox and Chrome show a warning before allowing code to be pasted into the console precisely to defend against this attack.

Example payload:
document.body.innerHTML.match(/FLAG\{.*?\}/g)

Category: Social Engineering - OWASP Top 10 #6
